How to copy the cache from Discord web:

  1. Open https://discord.com/app and sign in.
  2. Press Ctrl+Shift+I / Cmd+Option+I.
  3. Go to Application → Local Storage → https://discord.com.
  4. Find UserAffinitiesStoreV2, copy the value, paste it here.
