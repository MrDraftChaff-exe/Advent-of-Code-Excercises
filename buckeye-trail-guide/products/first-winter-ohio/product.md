# First Winter in Central Ohio Checklist

Central Ohio winters swing: ice one week, mud the next. Use this before the first hard freeze — not during it.

## Timing

| When | Do this |
| --- | --- |
| Early November | Build car kit; test battery; locate ice scraper |
| Before first freeze warning | Disconnect / store hoses; check heat works in every room |
| First snow forecast | Clear porch/walk plan; confirm shovel / salt location |
| January thaw cycles | Re-check kit; replace used items |

## Car kit

- [ ] Ice scraper + brush
- [ ] Small shovel
- [ ] Bag of salt / sand / kitty litter for traction
- [ ] Jumper cables or jump pack
- [ ] Blanket + spare gloves/hat
- [ ] Flashlight + batteries
- [ ] Phone charger / power bank
- [ ] Bottled water + non-perishable snack
- [ ] Reflective triangle or vest
- [ ] Washer fluid rated for freeze temps
- [ ] Tire pressure check (cold weather drops PSI)
