# Stadium Weekend Logistics Sheet

Generic logistics for a big-event weekend in Columbus (campus / arena corridor). No ticket tipsy chaos.

## Friday (T-minus 1)

- [ ] Confirm tickets are in the wallet app that will work with dead cell service
- [ ] Share a single group pin (meetup + backup indoor pin)
- [ ] Decide: **drive + park** · **rideshare both ways** · **park remote + rideshare last mile**
- [ ] Charge battery pack; pack portable charger
- [ ] Check bag policy for the venue
- [ ] Screenshot screenshots of tickets + parking map offline
- [ ] Set a hard “leave for venue” time alarm

## Parking vs rideshare decision tree

1. Is anyone sober designated driver? → prefer pre-paid lot or remote lot  
2. Staying walkable to Short North / campus edge? → rideshare or walk  
3. Group larger than 4? → driving often wins on cost if parking is secured  
4. Leaving exactly at peak exit? → walk farther before opening the rideshare app

## Weather & gear

- [ ] Know heat / storm / cold outlook by Friday night
- [ ] Shoes you can stand in for 4+ hours
- [ ] Clear bag / approved clutch only
- [ ] Layers for evening temp drop
- [ ] Cash small bills optional (some lots / tips)

## Exit strategy

- [ ] Agree “no wandering separated” rule for the first 20 minutes post-event
- [ ] Pick a non-surge street for pickup
- [ ] If driving: pre-write the turn-by-turn out of the lot (first two turns)
- [ ] Food plan after: reservation vs walk-up backup within 10 minutes of pin

## Sunday reset

- [ ] Hydrate / easy brunch
- [ ] Check parking citations email/app if any
- [ ] Return borrowed chairs / gear
- [ ] Note what you’d change next time (one line): ____________________

## One rule that prevents 80% of stress

One pin. One timeline owner. Everyone else just shows up.
