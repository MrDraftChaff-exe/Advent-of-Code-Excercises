# Metro Parks Starter Card

This is the **system card** — how to use Central Ohio parks without overthinking.  
For specific under-$15 outings, see the Nature guide; this card is the orientation layer.

**Not affiliated with park districts.** Hours, alerts, and rules change.

## Pick a park in 60 seconds

| If you have… | Choose… |
| --- | --- |
| 40 minutes | Small lake loop / neighborhood metro park |
| 90 minutes | One trail + overlook; leave when the timer ends |
| Half day | One larger park; pack water; don’t hop three lots |
| Kids / stroller | Paved or crushed stone loops first |
| Dogs | Confirm leash rules and which parks allow pets |

## Before you go

- [ ] Check park alerts (flooding, closures, hunts where applicable)
- [ ] Screenshot a map — signal dies in pockets of woods
- [ ] Water + one layer more than you think
- [ ] Tell someone your lot + return time for longer hikes

## Etiquette that keeps parks nice

- Stay on marked trails near bluffs and sensitive prairie
- Leash where required; pack out waste
- Headphones low enough to hear bikes/horses where shared
- No “shortcut” social-media bushwhacking

## Gear minimum

| Season | Minimum |
| --- | --- |
| Any | Water, phone, keys, map screenshot |
| Summer | Bug spray, sunscreen, tick check plan |
| Winter | Traction shoes, gloves, daylight deadline |
| After rain | Grip shoes — boardwalks get slick |
