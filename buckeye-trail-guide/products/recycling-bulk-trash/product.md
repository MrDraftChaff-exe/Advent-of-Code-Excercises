## Recycling — common yes / no (VERIFY LOCALLY)

| Usually OK if clean & dry* | Usually NOT in curbside* |
| --- | --- |
| Flattened cardboard | Plastic bags / film (often store drop-off) |
| Paper / mail | Food-soiled paper plates |
| Plastic bottles / jugs (check numbers) | Styrofoam |
| Metal cans | Tanglers (hoses, wires, holiday lights) |
| Glass bottles/jars (if your hauler takes glass) | Electronics / batteries |

\*Treat this as a memory aid — your hauler’s PDF wins.

## Bulk / large items

- [ ] Confirm whether you need an appointment, sticker, or special pickup week
- [ ] Measure doorway / elevator before you drag a couch
- [ ] Ask about fees for mattresses / appliances
- [ ] Remove personal data from electronics before disposal
- [ ] Offer usable furniture to neighbors / freecycle first

## Odd items — starting points

| Item | Start here |
| --- | --- |
| Batteries / bulbs | Retail take-back or county HHW events |
| Paint | HHW / reuse programs (don’t curbside-guess) |
| Meds | Pharmacy take-back / approved drop boxes |
| Scrap metal | Local scrap yard (call first) |
| Textiles / textiles | Donation if usable; otherwise hauler rules |

## Kitchen habit that fixes most recycling fails

Empty · rinse · dry · lids per local rule · **no wishcycling**.
