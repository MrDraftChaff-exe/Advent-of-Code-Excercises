# Apartment Walkthrough Photo Checklist

Do this **on move-in day** (and again before move-out). Photos beat memory.

## Rules

1. Lights on. Daytime if you can.
2. Wide shot, then close-up of every defect.
3. Include a timestamp (phone clock in-frame or metadata).
4. Upload to cloud **before** you lose the phone.

## Whole-home

- [ ] Front door / locks / keys tested
- [ ] Smoke + CO detectors present (note missing)
- [ ] HVAC filter condition / thermostat works
- [ ] Windows open/lock; screens intact
- [ ] Closets: rods, shelves, damage
- [ ] Floors: scratches, stains, soft spots
- [ ] Walls / ceilings: holes, stains, cracks
- [ ] Outlets / switches spot-check each room

## Kitchen

- [ ] Sink / disposal / shutoffs
- [ ] Fridge / freezer temps (or at least runs)
- [ ] Stove / oven / range hood
- [ ] Dishwasher (run a short cycle if possible)
- [ ] Cabinets / drawers / counters chips
- [ ] Under-sink water stains

## Bath

- [ ] Toilet secure / runs / leaks
- [ ] Tub/shower caulk, mold, drain speed
- [ ] Fan works
- [ ] Vanity / mirror / moisture damage

## Each bedroom / living area

- [ ] Carpet vs pad smells / stains
- [ ] Door latch / closet
- [ ] Ceiling fan wobble / lights
